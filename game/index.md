# FUN SHOOTER VR

**Aim • Shoot • Score • Win**

FUN SHOOTER VR is a virtual reality arcade shooting game from **Orenda Studio**, built for Meta Quest.

Test your aim across colorful shooting challenges featuring balloons, clay targets, birds, score rewards, weapon progression, and fast-paced VR gameplay.

## Game Features

- Arcade-style VR shooting challenges
- Balloons, birds, clay targets, and special targets
- Score, XP, coins, combos, and rewards
- Unlockable weapons and progression
- Designed for Meta Quest VR
